# Suporte remoto SENVIA

Route: `/suporte`. Built by Astro and published by the existing Vercel Git integration.

Downloads are served by Nginx at `https://suporte.senvia.pt/download/` from `/var/www/senvia-support-downloads/` on the VPS. No credentials or administrative tokens are sent to the browser. All packages enroll into the MeshCentral device group **Geral**.

| Variant | Download filename | MeshCentral binary ID |
| --- | --- | --- |
| Windows x64 | SENVIA-suporte.exe | 4 |
| Windows x86 | SENVIA-suporte.exe | 3 |
| Windows ARM64 | SENVIA-suporte.exe | 43 |
| macOS universal | SENVIA-suporte.zip | 10005 |
| Linux x64 | SENVIA-suporte.tar.gz | 6 |
| Linux ARM64 | SENVIA-suporte.tar.gz | 26 |

Windows executables include the server and enrollment settings generated by MeshCentral. macOS ZIP includes its installer package and uninstaller. Linux archives contain the matching ELF agent and `SENVIA-suporte.msh`; both files must be extracted into the same folder before installation.

Detection is local to the visitor's browser. User-Agent Client Hints provide architecture where supported; otherwise the page identifies the OS and recommends a version for confirmation. Manual selection always remains available, including without JavaScript through the all-downloads links. Mobile visitors are told to open the page on the target computer.

The Windows filename is set by the HTTP Content-Disposition header. Renaming is not equivalent to commercial Authenticode signing. macOS Gatekeeper, system permissions and Linux graphical-session restrictions still apply. Do not instruct visitors to disable endpoint protection.

The downloads are versioned snapshots generated on 2026-10-27. Regenerate and verify the packages after updating the MeshCentral agent binaries or changing the enrollment group. Keep the MeshCentral server's existing identity keys intact. Replacing the server identity invalidates old installers.

A public enrollment installer can be downloaded by anyone; administrators must review unexpected devices in Geral. It does not give visitors access to the administration console or existing devices.
